# Clock Out Alive / 摸鱼到下班 v1.13.0

v1.13.0 is a playfield-first presentation and game-feel release. It deliberately adds no new progression system or mandatory control.

## Active-run hierarchy

- hides the mission brochure, route strip, record panels and footer while a run is active;
- keeps only score, Combo, scene and clock in the primary HUD;
- moves event narration into the ticker instead of duplicating an event chip;
- suppresses ticker text while a scene-transition toast is visible;
- turns the progress bar into a thin edge indicator instead of a large framed strip.

## Start screen and mobile

Desktop menu presentation is now a left-weighted launch panel so the office scene remains visible before play. Portrait mobile removes the truncated brand and redundant HUD text during runs, reduces the tutorial to a compact lower-edge hint and provides a rotate/fullscreen prompt below the playfield.

## Character readability

The runner is rendered 10% larger around the same foot anchor while physics and hitboxes remain unchanged. Stage-transition duplicate floaters are removed so gameplay text no longer stacks over scene banners.

## Compatibility

Daily Shift, local Top 5 history, scene-specific obstacle behaviors, Leave Slip, Risk Form, near-miss tiers, endings and the canonical release pipeline remain unchanged.
