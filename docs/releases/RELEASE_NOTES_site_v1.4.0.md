# 91hwl site v1.4.0

91hwl site v1.4.0 is a homepage clarity and version-synchronization release. It keeps both playable runtimes unchanged while presenting their current public releases accurately.

## Homepage

- Replaces the generic “Open. Just play.” hero with a direct two-game proposition in Chinese and English.
- Shortens the lead to one clear Dungeon Echo sentence and one Clock Out Alive sentence.
- Replaces the repeated long-form story block with a compact “choose your run” comparison: 100-floor build/retreat pressure versus a roughly four-minute reaction runner.
- Adds visible current-version context to both hero cards and keeps the full project cards, trust hub, theme, language and accessibility contracts.
- Preserves the accepted light/dark visual system and responsive layout; the new comparison becomes two columns on tablet and one column on phones.

## Current release presentation

- Dungeon Echo detail copy now presents v1.4.2 paged Echo Town and the 1120×460 walkable plaza.
- Clock Out Alive detail copy now presents v1.17.0 four-minute pacing, animated scenes and the portrait playfield up to 440px.
- Structured VideoGame versions, homepage cards, detail pages and footer all share the same release numbers.

## Release boundary

- Site: v1.4.0
- Dungeon Echo: v1.4.2
- Clock Out Alive: v1.17.0
- The playable game runtime files are not changed by this site release.
