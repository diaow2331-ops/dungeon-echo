# 地牢回响：真人游玩平衡基线

> 目标：优先保证“玩家手里好玩、强路线有代价、危险可理解”。Bot / simulation 用于发现死亡墙、资源异常和循环问题，不作为四职业等强目标。

## 当前生产基线

当前公开路线固定为 `classic-100`。职业基础校准由 `gameplay-tuning.js` 管理，装备、成长、城镇和章节内容分别由独立生产模块补充。

### 战士

- 当前基线：40 基础生命；横扫 CD 5；“坚甲”提供随等级成长的稳定减伤。
- 战斗身份：正面推进、承压、横扫控场、反击/续航构筑。
- 主要风险：近战天然要承担接敌和换血成本，不能靠单一防御属性永久免疫危险。
- 反高防机制已经改为**可观察的破甲预警与反制窗口**，不再使用“防御越高越容易随机被全额穿透”的旧规则。

### 游侠

- 当前基线：直线 4 格普通远射；“灵巧”可闪避部分近战攻击；疾步负责风筝、穿阵和脱离。
- 战斗身份：位置管理、射线控制、持续远程输出。
- 主要风险：远程优势必须依赖地形和移动决策；不应形成只后退就能长期无伤的唯一解。
- 自动模拟会低估真人玩家的走位上限，因此游侠平衡不能只看 bot 通关率。

### 秘术师

- 当前基线：直线 3 格普通奥术射击；主动奥术弹负责跨角度爆发、击退和处理高威胁目标。
- 战斗身份：脆弱炮台、爆发窗口、冷却管理。
- 主要风险：站位错误的惩罚应明显，但主动技能冷却期不能退化成被迫低血贴脸近战。

### 刺客

- 当前基线：26 基础生命；天生暴击优势；影袭 CD 7。
- 战斗身份：高风险斩首、瞬移、处决和连续猎杀。
- 主要风险：影袭没有完成击杀时必须认真处理位置与撤离，不能稳定无成本连跳滚雪球。

## 当前构筑判断

职业平衡不只由职业基础数值决定。当前生产版本已经同时包含：

- 六栏装备；
- 职业适配与内在价值分离；
- 史诗/传说机制词缀；
- +3 精炼方向与 +5 淬炼；
- 职业天赋分流；
- 可预警敌人机制；
- 城镇补给、回城、检查点和经济压力。

因此后续平衡应检查“完整构筑 + 场景 + 资源”的实际行为，不应只针对某一项 ATK / DEF / HP 做孤立调整。

## 真人试玩优先观察

1. 同等进度下，是否存在某职业无需承担明显风险就能长期压制其他职业；
2. 10 / 20 / 30 / 60 / 90 等关键章节是否出现无解释的职业失效区间；
3. 战士普通接敌是否仍需要异常高频喝药；
4. 游侠是否能通过单一走廊后退套路长期无伤；
5. 秘术师是否能在主动技能真空期保持远程炮台节奏；
6. 刺客影袭失败后是否存在真实的位置风险；
7. 各职业药水消耗、平均承伤和清怪回合数可以有明显差异，但不应出现数量级差距；
8. 强构筑是否同时拥有玩家能理解的代价或敌方反制；
9. 回城、锻造、买补给与继续深入之间是否存在真实竞争，而不是永远只有一个正确答案。

## 数据使用原则

- `test/sim.cjs`：用于定位结构性异常，不是产品验收分数。
- 短 Profile：确定性开发/回归夹具，不代表正式玩家模式。
- `classic-100`：唯一生产长局，需要以真人游玩证据持续补充。
- 修改平衡时优先解释“为什么玩家会这样行动”，再决定是否需要改数值。

## 当前暂不做

- 不因为 bot 深层低胜率连续全局削怪；
- 不追求四职业完全一致 DPS、生存或通关率；
- 不通过无限堆生命/防御掩盖机制问题；
- 不重新引入隐藏随机惩罚来克制强构筑；
- 不在缺少真人长局证据时进行大范围第二轮职业数值重做。

后续完整 1→100 真人经济/难度审计以 `PRODUCTION_ROADMAP.md` 和当前 Issues 为准。
