地牢回响 Dungeon Echo v1.2.3
============================

纯静态、离线优先的单机网页 Roguelike。
正式旅程从第 1 层开始，直至第 100 层终局；核心玩法不依赖账号、后端或数据库。

v1.2.3 最终设备 / 美术收尾
------------------------
- PC 与手机统一移除主角常驻职业光晕和技能就绪椭圆环。
- 视觉叠加层现在按当前 40×28 / 17×17 / 15×15 相机窗口换算坐标，不再把随角色移动的光效画到错误位置。
- 手机非全屏浏览器下不再让顶部状态栏和底部控制区承担 sticky + backdrop-filter 的高成本组合，减少地址栏伸缩时的上下抖动与合成卡顿。
- 手机高频操作改为 pointer-down 即响应；方向长按更早进入连续移动。
- 手机方向盘中央“等待一回合”按钮取消触控目标，只保留四向移动，避免斜按/连续移动时误耗一回合。
- 手机视觉叠加层降低非关键绘制频率并跳过装饰性浮尘；核心地图、守卫预警和战斗状态不变。
- 不修改敌人/Boss 强度、Mana、掉落率、经济、存档 schema 或 1→100 内容。

v1.2 核心更新
------------
- J 为主动攻击、K 为职业技能；移动与攻击职责分离。
- 四职业拥有独立蓝量上限、技能消耗与回复节奏。
- 中文 / English：?lang=en / ?lang=zh、浏览器语言首选、标题页选择与本地记忆。
- 自适应程序化 BGM + 独立 Music / SFX 0–100% 音量；M 与手机声音按钮共用总静音。
- 手机竖屏/横屏独立拇指布局、长按连续移动、震动反馈。
- 地面装备使用真实 v13 分层美术；角色装备叠层保持关闭。
- 锻造、城镇、百层守卫和终局反馈已经完成当前阶段收尾。

核心内容
--------
- 四职业：战士、游侠、秘术师、刺客。
- 六装备栏：武器、护甲、头盔、靴子、戒指、项链。
- 史诗/传说机制词缀与 +1～+5 锻造。
- 贪婪远征：下潜搜刮 → 判断是否继续冒险 → 回城保住战利品 → 城镇整备 → 再次深入。
- 10→100 守卫/终局节点拥有可读预警、反制和阶段机制；第 100 层为三阶段终局战。
- 四职业在 20 / 40 / 60 / 80 层获得二选一主动技能进化。
- PC 支持键鼠 / Gamepad；手机使用四向方向盘和独立动作区。

操作
----
移动       方向键 / WASD / 点击已探索地块
攻击       J（按当前面向）
等待       空格 或 .（手机方向盘不再提供中央等待键）
职业技能   K（消耗蓝量）
药水       Q
卷轴       E
回城       T（贪婪远征）
下楼       Enter（站在楼梯上）
暂停       Esc
声音       M（总静音；音乐/音效可独立调节）
全屏       F
重开       死亡或胜利后按 R

存档
----
进度保存在当前浏览器的 localStorage 中，不会上传到云端。
清除站点数据、使用另一浏览器配置/设备，或更换存储来源可能导致进度不可用；
v1.2.3 继续保留现有 de-run-v6 v2 run save 与 de-greedy-meta-v1 元进度结构，不要求迁移或清档，也不提供云存档。

本地运行
--------
在本目录运行：

  python3 -m http.server 8000

然后访问：

  http://localhost:8000/

英文直达：

  http://localhost:8000/?lang=en

index.html 为正式 1→100 路线；dev.html 与短 Profile 仅用于开发测试。
