地牢回响 Dungeon Echo v6.2
==========================

离线单机网页游戏。解压后用浏览器打开 index.html 即可（Chrome / Edge / Firefox）。
不需要安装、不需要联网、不会上传任何数据。

操作
----
移动     方向键 / WASD / 点击已探索地块
等待     空格 或 .
药水     Q
卷轴     E
回城     T（贪婪远征：撕掉回城卷轴，带着战利品平安回镇）
职业技能 C
下楼     Enter（站在楼梯上）或点击「下潜」
暂停     Esc
静音     M
全屏     F
重开     死亡或胜利后按 R

贪婪远征（类《贪婪洞窟》玩法）
------------------------------
标题界面点「贪婪远征」开关开启。核心循环：

  出发下潜 → 越深战利品越好 → 随时按 T 回城落袋为安 → 回镇存仓库 / 买补给 → 再下去

- 死亡惩罚：死亡不再删档结束，而是失去「背包所有物品 + 随身金币」，
  已穿装备保留，回到小镇重来。贪心越深，摔得越疼。
- 回城卷轴：初始带 2 张；地牢商人有售；中层守卫必掉一张。按 T 即可把
  背包与金币完整带回——是保住战利品的唯一方式。
- 城镇：金库（金币绝对安全）、仓库（存入的装备死亡夺不走）、
  补给商店（药水 / 回城卷轴 / 钥匙）。出发后从第 1 层重新开始。
- 元进度持久化：等级、经验、天赋、已穿装备、金库、仓库跨远征保留
  （localStorage 键 de-greedy-meta-v1）；每次远征独立随机种子，同次数可复现。
- 与经典模式完全隔离：各自的存档互不可见，随时切换互不干扰。

新内容（相对 v6.1）
------------------
- 游侠现在真的能射箭了：面朝敌人所在直线方向（射程 5 格内、无墙遮挡）移动即自动射箭，无需再贴脸近战。
- 标题界面新增「下潜深度」选择：10 / 20 / 30 / 40 / 50 / 60 / 100 层，点选后切换整套内容（新怪物、新地图主题、新中层 Boss、新终局 Boss）。
- 40 / 50 / 60 层为全新扩展：31 层起接续经典线，新增 14 种怪物与 10 个地图主题，30 / 40 / 50 层新增中层 Boss。
- 下潜规则：中层 Boss（第 10 / 20 …层）不锁楼梯，可以绕过直接下楼；但击杀必掉史诗装备 · 金币 · 钥匙 · 治疗药水。本层有守卫存活时，HUD 敌人计数会亮起 ⚑ 橙色标记。终局层 Boss 必须击败并做出抉择。
- 注意：存档只有一个槽位，按深度档位区分；切换档位后旧档位的“继续冒险”会消失，需要在新档位里重新推进存档，会覆盖旧存档。

修复（v6.2）
-----------
- 修复：暂停界面的「保存」此前实际未写入（写盘发生在状态切换之后），「继续冒险」依赖的是每 4 回合的自动存档；现在暂停即落盘，「保存并回标题」同步生效。
- 清理无任何引用的遗留原型代码（__controlsTest）。

新内容（相对 v6.2）—— 地牢机制打磨
------------------------------------
- 怪物特性（traits）：深层怪物开始拥有独特战斗能力，让地牢不再是清一色近战砍杀
  · 再生（regen）：每回合回复少量生命——幽魂、霜怨灵、缝合憎恶等，不速战速决就会被耗住；
  · 爆炸（boom）：死亡时对相邻玩家造成溅射伤害——血教徒、深渊恶魔、裂隙龙裔，需要用远程或拉开距离解决；
  · 狂暴（enrage）：生命降到一半以下时攻击暴涨——墓园巫妖、虚空幼体，残血才是最危险的时候；
  · 远程（ranged）已实装远程射击：霜语法师 / 墓园巫妖 / 陨星使会在射程内隔空丢法术，射出的光矢可见。
  前 11 层为纯基础怪节奏，12 层起这些能力逐步登场，难度曲线扎实平滑。
- 木桶：每层 2-5 只可踢破的木头容器，是贪婪洞窟式的免费补给——金币 / 治疗药水 / 装备随机掉落，
  偶尔是空桶。走到上面即打破，无钥匙要求，属于路过的惊喜。
- 机制不变式：以上全部通过 fail-closed profile 校验与确定性回归，与旧档完全兼容。

新内容—— 幸运转盘（城镇金币回收站）
------------------------------------
- 城镇新增八格轮盘：进镇自动生成，奖品在开格时即已固定——
  金币大小奖 / 药水 / 卷轴 / 钥匙 / 回城卷轴 / 装备 / 保险符 / 空门。
- 抽奖：付费随机开一格；重置：付费重摇全部八格。
- 定价随使用递增：抽奖费 = 40 + 20×抽数，重置费 = 60 + 40×重置数，
  计数持久化在元档——越玩越贵，纯度极高的金币回收池；
  死亡（含保险符结算）后计数归零、轮盘重摇：死神的怜悯。
- 与稀缺掉落联动：地牢里装备难获得 → 金币攒着 → 转盘搏运气或商店锻造稳收益，
  「赌一把还是稳一手」成为城镇里的新抉择。
- 奖池 v2 平衡修正：装备合计仅 5%（稀有≥2 的 4% + 史诗≥3 的 1%——普通装
  不进轮盘），药水 9%，空门 35%，金币奖深度锚定且期望为负——
  转盘是娱乐税与梦想购买处，不是刷装备的捷径。
- smoke 第 18+19 节锁定：递增费用公式、抽奖/重置精确扣费与计数、
  金币不足拒绝、各奖种结算单元、死亡归零、奖池占比合同
  （装备 ≤8%、药水 ≤12%、空门 ≥25%、轮盘装备稀有度 ≥2）。

新内容—— 掉落经济学：贪婪洞窟式稀缺性
------------------------------------
- 审计发现旧值严重超发：classic-30 每层约 8-9 件装备、7 瓶药水，
  传说权重 5%（每 2-3 层一件传说）——完全违背「装备难获得」的核心魅力。
- 全面收紧（按档位递进，深层更吝啬）：
  · 击杀掉落：装备 40%→8~14%、药水 32%→11~15%，金币成为击杀主要产出；
  · 地面刷新：装备两处概率近乎减半、药水 2-4 瓶→1-2 瓶；
  · 稀有度权重：普通50 / 精良27 / 稀有14 / 史诗7 / 传说2——
    传说从「每几层一件」变成真正的传家宝级奖赏。
- 保持不变的锚点：精英必掉装备（猎杀精英=核心farm策略）、
  中层守卫必掉史诗、Boss 奖励、城镇商店与锻造（金币有了新去处）、
  每层保底 minPotions/minEquips（不至于断粮）。
- smoke 第 17 节锁定：全部档位掉率上限合同、seeded 稀有度统计
  （传说 ≤4%、史诗+传说 ≤11%）、精英连杀必掉。

新内容—— 平衡反制：破甲一击与重伤
------------------------------------
- 破甲一击：当你的防御超出怪物攻击力时，怪物获得无视护甲的重击概率
  min(45%, 超出/30)——防御适度依然划算（前期不变），但堆到免疫墙附近时
  怪物近半回合打出全额伤害，「神装无敌」到此为止。
- 重伤：精英 / 层守卫 / 终局 Boss 命中后施加 3 回合重伤——期间吸血、药水、
  卷轴、神龛、击杀回复全部减半，自然回复停止。专治「吸血站桩」。
- 设计立场：不削弱装备爽感（词缀数值原样），而是给敌人反制手段；
  死亡威胁回归，贪婪远征的保险符与仓库才有意义。
- smoke 第 16 节锁定：破甲公式精确值 / 免疫墙统计破壁 / 重伤施加规则 /
  药水·吸血减半的精确结算。

新内容—— 词缀扩充：反伤与击杀回复
------------------------------------
- 反伤（thorns）：受近战攻击时反弹固定伤害，可反死敌人并正常结算掉落——
  坦克流核心词缀，配高防护甲越挨打越赚。
- 击杀回复（regen）：每次击杀回血（上限封顶）——清怪续航件，缓解深层消耗压力。
- 词缀池按 profile 声明自适应：genAffix 只从声明了数值区间的种类中抽取，
  未来加词缀只需在 profile 里补一行区间；validateProfile 现强制要求 8 种区间。
- 数值：thorns = 1+层/4，regen = 2~3+层/4；评分权重 thorns ×2、regen ×1
  （锻造费与售价自动联动）。
- smoke 第 15 节锁定：profile 静态合同 / 精确反弹 / 反伤致死入账 / 无反伤不反弹 /
  回复精确与封顶 / 160 次生成无非法词缀且新词缀实际出现。

新内容—— 快速下潜与保险符
------------------------------------
- 快速下潜（经典/贪婪通用）：站在楼梯上按 J（或点「快速下潜」浮钮），
  向回响支付金币直坠 5 层。费用公式 n×(8+当前层×4)，随深度递增；
  超量跳层自动夹到最终层；终局 Boss 封锁时照常拒绝；金币不足零扣费。
  跳层意味着放弃中间层的物资与经验——用钱换时间，贪婪洞窟味的核心取舍。
- 保险符（城镇商店 120 G）：持有期间死亡，背包物品完好带回小镇、保险符消耗一张，
  随身金币仍坠入深渊；药水/卷轴/穿戴在 insured 结算中同步不凭空回复。
  与仓库形成双保险：常备装备进仓库，搏一搏的战利品靠保险符兜底。
- 以上全部有确定性回归锁定：smoke 第 14 节（费用公式/拒绝路径/夹层/Boss 封锁/
  购买扣费/死亡保包/符号消耗/insured 同步/脏档修复）。

新内容—— 百层远征（classic-100）
------------------------------------
- 新档位「回响无尽 · 一百层」：1-60 层沿用经典线，61 层起压进「无光深渊 / 终焉王座」，
  共 16 个地图主题轮换；第 10/20/30/40/50/60/70/80/90 层中层 Boss 均可绕过或击杀，
  第 100 层终局 Boss 必须击败，掉落「终焉之心」，拾取后可选离开结算或踏入无尽回响。
- 装备成长线延伸到 92 级需求：星蚀 / 混沌系列武器、铠甲、戒指对应百层数值曲线。
- 端到端回归 test/descent100.cjs：直驱引擎从第 1 层清怪下潜到第 100 层，
  验证楼梯生成、9 个中层 Boss 按层出现、终局层封锁楼梯、心脏掉落与拾取、
  无尽回响抉择到 won 的完整胜利链路（13 项断言）。

新内容（相对 v6）
----------------
- 新职业「刺客」：血薄攻毒，技能「影袭」可瞬移至视野内最近敌人身侧，打出必定暴击的偷袭。
