地牢回响 Dungeon Echo v1.2.2
============================

纯静态、离线优先的单机网页 Roguelike。
正式旅程从第 1 层开始，直至第 100 层终局；核心玩法不依赖账号、后端或数据库。

v1.2.2 最终游戏收尾
-------------------
- 语言系统重构为“单次语言锁定 + 标题页选择 + 整页重载”：不再在运行中的地牢里做全页热切换。
- 旧 i18n 轮询/全局字符监听链退出生产包，动态翻译只处理新渲染内容和少数状态节点，降低长时间游玩卡死风险。
- 英文模式继续覆盖装备、常见怪物/守卫、伤害日志、金币、Mana、锻造与操作提示；存档/内容 ID 不随语言改变。
- 地面掉落增加克制的落地阴影、类型/稀有度光晕与微弱拾取闪光；只渲染当前视野与视线范围内物品，不泄露黑暗区域。
- 角色装备叠层继续保持关闭；本轮不把装备重新贴回角色立绘。
- 铁匠铺补充 +N→+N+1 强化反馈、实际金币花费、属性增量、锻造 +N/5 阶段、+3 精炼解锁与 +5 淬炼完成提示；强化数值本身不变。
- 发布健康检查改为独立验证游戏 HTML 与 /dungeon-echo/VERSION，不再依赖页脚文案作为版本事实来源。
- 不修改敌人/Boss 强度、Mana 参数、掉落率、经济、存档 schema 或 1→100 内容。

v1.2 核心更新
------------
- J 为主动攻击、K 为职业技能；移动与攻击职责分离，不再靠撞怪作为主要攻击输入。
- 四职业拥有独立蓝量上限、技能消耗与回复节奏；蓝量最终状态沿用现有 run save 持久化，刷新不能恢复旧快照套利。
- 中文 / English：?lang=en / ?lang=zh、浏览器语言首选、标题页选择与本地记忆。
- 自适应程序化 BGM + 独立 Music / SFX 0–100% 音量；推荐 30 / 85，M 与手机声音按钮共用总静音。
- 手机竖屏/横屏独立拇指布局、长按连续移动、震动反馈；新手提示不会覆盖主操作区。
- 手机 Safari / Chrome 切后台再回来后，后续手势可恢复 WebAudio。
- 晚期人类体验压力轻量补强：1–20 层保持不变，普通敌人到 100 层最多约 +8% ATK，精英额外约 +3%，守卫/终局基础攻击仅小幅提高；不增加隐藏穿甲、HP、掉率或经济惩罚。
- 地面装备使用真实 v13 分层美术。

核心内容
--------
- 四职业：战士、游侠、秘术师、刺客；战斗节奏与构筑方向不同。
- 六装备栏：武器、护甲、头盔、靴子、戒指、项链。
- 史诗/传说机制词缀，不只提升面板，也会改变移动、等待、技能、喝药与普攻决策。
- +1～+5 锻造；+3 选择精炼方向，+5 完成对应淬炼。
- 贪婪远征：下潜搜刮 → 判断是否继续冒险 → 回城保住战利品 → 仓库/金库/市集/锻造整备 → 再次深入。
- 已征服检查点：只有真正通过上一阶段守卫后，才会解锁更深的回返点。
- 城镇有限补给、章节价格、幸运转盘与死亡风险共同构成长局经济。
- 10→100 守卫/终局节点拥有可读预警、反制和阶段机制；第 100 层为三阶段终局战。
- 四职业在 20 / 40 / 60 / 80 层获得二选一主动技能进化。
- PC 与手机拥有独立操作布局；支持键鼠、Gamepad 与手机触控。

操作
----
移动       方向键 / WASD / 点击已探索地块
攻击       J（按当前面向）
等待       空格 或 .
职业技能   K（消耗蓝量）
药水       Q
卷轴       E
回城       T（贪婪远征）
下楼       Enter（站在楼梯上）
暂停       Esc
声音       M（总静音；音乐/音效可独立调节）
全屏       F
重开       死亡或胜利后按 R

存档
----
进度保存在当前浏览器的 localStorage 中，不会上传到云端。
清除站点数据、使用另一浏览器配置/设备，或更换存储来源可能导致进度不可用；
v1.2.2 继续保留现有 de-run-v6 v2 run save 与 de-greedy-meta-v1 元进度结构，不要求迁移或清档，也不提供云存档。

本地运行
--------
在本目录运行：

  python3 -m http.server 8000

然后访问：

  http://localhost:8000/

英文直达：

  http://localhost:8000/?lang=en

index.html 为正式 1→100 路线；dev.html 与短 Profile 仅用于开发测试。
