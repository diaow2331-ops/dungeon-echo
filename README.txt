地牢回响 Dungeon Echo v1.0.0
============================

纯静态、离线单机网页 Roguelike。正式旅程从第 1 层开始，直至第 100 层终局。
推荐通过网站或本地 HTTP 服务器打开 index.html；无需账号、后端或联网存档。

正式内容
--------
- 四职业：战士、游侠、秘术师、刺客；职业机制、武器池、选职肖像和实战造型各不相同。
- 六装备栏：武器、护甲、头盔、靴子、戒指、项链。
- 史诗/传说机制词缀、锻造、商店、天赋、神龛、陷阱、密室与章节守卫。
- 贪婪远征：下潜搜刮 → 用回城卷轴保住战利品 → 仓库/金库/市集整备 → 再次深入。
- 每 10 层一位深层守卫；第 100 层必须击败终局 Boss 并作出回响抉择。

操作
----
移动       方向键 / WASD / 点击已探索地块
等待       空格 或 .
药水       Q
卷轴       E
回城       T（贪婪远征）
职业技能   C
下楼       Enter（站在楼梯上）
暂停       Esc
静音       M
全屏       F
重开       死亡或胜利后按 R

存档
----
进度保存在当前浏览器的 localStorage 中，不会上传。清除站点数据、使用另一浏览器配置
或更换站点来源可能导致进度不可用；v1.0.0 不提供云存档。

本地运行
--------
在本目录运行：

  python3 -m http.server 8000

然后访问 http://localhost:8000/ 。dev.html 与短档位仅供开发测试，不属于游客入口。

发布验证
--------
  node --check game.js
  node test/production.cjs
  node test/descent100.cjs
  node test/smoke.cjs
  node test/release.cjs
